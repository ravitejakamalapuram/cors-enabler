# Changelog

All notable changes to CORS Enabler Engine are documented here. The extension
version comes from `package.json` and is written into the built manifest.

## [1.0.1] - 2026-09-22

### Changed
- Privacy policy URL moved to the dedicated GitHub Pages site
  (https://ravitejakamalapuram.github.io/cors-enabler.html) and the extension
  was resubmitted to the Chrome Web Store.
- Removed unrelated app-builder scaffolding (backend/, frontend/) from the repo.
- Onboarded to the shared CI/CD workflows with Chrome Web Store listing assets.

## [1.0.0] - 2026-09-21

### Added
- Initial Manifest V3 release: one-click CORS relaxation via
  `declarativeNetRequest`, per-domain/per-origin rules, presets, and a
  diagnostics view for rule matches.
